# HealthTrail Hospital | PCI DSS & HIPAA Compliance Assessment

## Project Overview

HealthTrail Hospital is a healthcare organization operating one main hospital and two outpatient clinics, with approximately 220 employees. Its operations rely on Electronic Health Record (EHR) systems, payment terminals, an online patient portal, cloud-hosted applications, and third-party service providers.

The increasing integration of payment systems and healthcare technologies introduces cybersecurity and compliance challenges, particularly in protecting cardholder data and electronic protected health information (ePHI).

An initial assessment identified weaknesses in payment environment segmentation, Cardholder Data Environment (CDE) scoping, employee access privileges, and periodic access reviews.

The assessment applies **PCI DSS v4.0.1** and the **HIPAA Security Rule** to evaluate these weaknesses, identify associated risks, and recommend practical security controls to strengthen payment security and patient information protection.

## Assessment Objectives

- Identify systems and connections relevant to the Cardholder Data Environment.
- Evaluate payment environment segmentation and recommend appropriate network restrictions.
- Assess employee access to patient information against HIPAA Security Rule requirements.
- Identify excessive access privileges and weaknesses in access review processes.
- Develop corrective actions, proposed control ownership, and verification requirements.

## Assessment Scope

### PCI DSS - Payment Security

The PCI DSS assessment considers payment terminals, the online patient portal, payment processing connections, relevant network infrastructure, and systems that may affect the security of the payment environment.

### HIPAA - Patient Information Protection

The HIPAA assessment focuses on employee access to ePHI within the EHR environment, including role-based access restrictions, authorization procedures, workforce role changes, and periodic access reviews.

## Frameworks Applied

**PCI DSS:** Payment Card Industry Data Security Standard v4.0.1

**HIPAA:** Health Insurance Portability and Accountability Act - Security Rule

## Project Deliverables

- PCI DSS Network Segmentation and CDE Scoping Assessment
- HIPAA Access Control and ePHI Protection Assessment
- Prioritized Security Remediation Action Plan
